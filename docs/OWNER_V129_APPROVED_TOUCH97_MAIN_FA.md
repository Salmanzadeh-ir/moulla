۳. ویژگی‌های تاریخی مورد تأیید — گالری ۱۰۵‌تایی، شش عنوان اصلی لاله‌زار، دوره آفلاین ۱۰۱۹ صوت، شنیدن دوسوم بدون احتساب Seek، یادداشت‌ها، یادآورها، بازگشت، رضایت محتوا و پخش بومی در پس‌زمینه — باید حفظ شوند. ترک عادی برنامه پخش را متوقف نمی‌کند؛ حذف Task از Recents آن را متوقف می‌کند و زمان شنیدن واقعی ذخیره می‌شود.

۵. هیچ شاخه، تگ، Release، APK یا فایل پشتیبان قدیمی حذف نشود. پشتیبان قابل‌بازیابی خارج از GitHub و اجازه صریح موردی، برای هر حذف لازم است.

۶. قفل Git blob و CI فقط **تغییر ناخواسته را آشکار و در مسیر آزمون رد می‌کنند**، نه اینکه از Push یا حذف مدیریتی مطلقاً جلوگیری کنند. GitHub Rulesets برای `main`، شاخه‌های `archive/*` و `download/*` باید با دسترسی مدیریتی فعال و نتیجه API بررسی شوند.
