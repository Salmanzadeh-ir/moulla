# نسخه آزمایشی «صفحه جدید» V9 — پای منبر مولا

**وضعیت:** جایگزینی سورس فعال شاخه `main` با طرح جدید هفت‌گزینه‌ای، با اجازه صریح مالک در ۱۲ نوامبر ۲۰۲۶. این تغییر **به معنی انتشار نسخه رسمی جدید نیست**.

## تاریخچه محفوظ

نسخه رسمی تأییدشده `10.4.9`، تگ `v10.4.9`، فایل APK اصلی و هش‌های تاریخی آن باید دست‌نخورده باقی بمانند. پوشه `design/` و قفل‌های قدیمی بازنویسی نشده‌اند. آزمون قفل تاریخی روی تگ مربوط اجرا می‌شود؛ آزمون سورس جدید با `scripts/verify_v9_preview.py` است.

## منوی اصلی نسخه جدید

۱. شرح جامع صوتی نهج‌البلاغه (آرشیو/جلسات موجود)
۲. توحید کاربردی (۵۰ جلسه)
۳. دیدن خدا در زندگی (۱۷ جلسه)
۴. شرح اصول کافی (۵۹ ردیف)
۵. کلیپ‌های تصویری (گالری چرخشی عمودی ۹:۱۶؛ **لینک‌های واقعی هنوز وارد نشده‌اند**)
۶. عکس نوشته (۱۸ تصویر اصلی با چرخش سه‌بعدی، لمس چپ و راست و پخش خودکار)
۷. یک جمله مهمان مولا (حکمت تصادفی؛ **فقط پنج رکورد آزمایشی**)

«درباره ما» و گالری ۱۰تصویری، خروج، پخش آپارات در قاب ۱۶:۹، مسیرهای بازگشت و ورود/بازگشت از ایتا از نسخه آزمایشی V9 منتقل شده‌اند. نمایش متن حکمت‌های بلند در قاب مرکزی اسکرول مستقل دارد؛ ایوان ثابت می‌ماند.

## محتوا و منبع

ورودی WebView: `app/src/main/assets/index.html` و داده‌ها: `lessons.json`, `life.json`, `kafi.json`, `library.json`, `session_manifest_v8.json`.

تصاویر اختصاصی طرح جدید: `images/new_ui_bg.png` و `images/new_ui_menu.png`. **هر دو تصویر اصلی از APK آزمایشی نصب‌شده استخراج و بایت‌به‌بایت ثبت شده‌اند؛ تصاویر تأییدشده نسخه ۱۰.۴.۹ تغییری نکرده‌اند.** ۱۸ عکس‌نوشته در `images/guest_album/` و ۱۰ تصویر «درباره ما» در `images/gallery/` قرار دارند.

بانک ۴۸۰ حکمت با ترجمه کامل هنوز موجود نیست. ترجمه پنج رکورد فقط نمونه است و نباید به نام مترجمی غیرواقعی یا به عنوان بانک نهایی معرفی شود. بخش کلیپ نیز هنوز فاقد لینک ویدئوی واقعی است؛ برای انتشار عمومی، مالک باید محتوای معتبر را تأیید کند.

## ساخت و آزمایش

- Java 17، Gradle 8.7 و Android SDK platform 35 / build-tools 35.0.0
- ساخت: `gradle --no-daemon :app:assembleDebug`
- فایل خروجی: `app/build/outputs/apk/debug/app-debug.apk`
- شناسه آزمایشی با پسوند `.newiwanv9` مستقل از برنامه رسمی است؛ برای نصب آن نیازی به حذف برنامه اصلی نیست.
- کنترل ثابت محتوا/منابع: `python3 scripts/verify_v9_preview.py`
- آزمون اختیاری مرورگر موبایل: `pip install playwright && python -m playwright install chromium && python tests/v9_browser_smoke.py`
- آزمون واقعی روی گوشی: نصب، ۷ بخش، اسکرول‌ها، بازگشت از ایتا، مرور ۱۸ عکس، «درباره ما»، بررسی پخش آپارات و بازگشت از تمام صفحات.

**محدودیت آزمون:** کنترل مرورگر، نصب و پخش واقعی اینترنت را اثبات نمی‌کند. انتشار APK/AAB رسمی و امضای کلید تولید نیازمند اجازه جداگانه مالک است.
