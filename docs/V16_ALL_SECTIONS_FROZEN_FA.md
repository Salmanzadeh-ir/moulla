# قفل سراسری نسخه آزمایشی V16 — درخواست صریح مالک

تاریخ: ۱۴ نوامبر ۲۰۲۶. این سند ناظر بر **سورس فعال** است و هیچ تغییری در تگ/نسخه رسمی تأییدشده ۱۰.۴.۹ ایجاد نمی‌کند.

تمام هفت بخش منوی اصلی، ظاهر و قاب ایوان طلایی، دکمه‌های خروج و بازگشت، جلسات صوتی و لینک‌ها، کلیپ‌ها، گالری درباره ما، ۹۳ عکس‌نوشته و قرعه تصادفی آن، تمام ۴۸۹ حکمت آفلاین، متن عربی با امیری، ترجمه فارسی با ساحل نیمه‌ضخیم، ابزار کپی با نشانی ایتا و اندازه متن درشت، در وضعیت فعلی **منجمد** هستند.

درخواست مالک: هیچ بخش یا متن یا تصویر یا رفتار آن تغییر نکند **مگر با دستور صریح جدید از خود مالک**. ابزارهای خودکار نباید قفل را به‌طور خودسرانه به‌روز کنند. برای تغییر مجاز جدید: ایجاد شاخه جدا، تأیید مالک، آزمون APK، ثبت هش قفل جدید، PR و بازبینی.

## پیاده‌سازی فنی

`design/v16-current-preview-lock.json` هش Git blob برای همه فایل‌های فعال `app/` را نگه می‌دارد. اسکریپت `verify_current_preview_lock.py` هر تغییر، حذف یا اضافه را در GitHub Actions تشخیص می‌دهد؛ `verify_v16_preview.py` تعداد محتوا و ابزارها را کنترل می‌کند. فایل `.github/CODEOWNERS` صاحب مخزن را به‌عنوان مسئول معرفی می‌کند.

**محدودیت:** هش و اسکریپت خودشان قابل تغییر توسط کسی با دسترسی نوشتن‌اند. برای قفل دسترسی واقعی، مالک باید در GitHub Settings → Rulesets/Branches الزام Pull request، Code owner review و موفقیت وضعیت `verify-ui-lock` را روشن کند. از این اتصال امکان فعال‌سازی آن تنظیمات ادمین در دسترس نیست. این قفل در مقابل مدیران مخزن غیرقابل‌شکستن نیست.
