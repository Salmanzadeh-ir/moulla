Paye Menbare Mola — Android V9 Preview (Approved Golden Iwan)

This is the FULL ANDROID SOURCE PROJECT, not an installable APK.

1. Extract this ZIP.
2. Copy all extracted files and folders into the existing PayeMenbareMola-Test GitHub repository root, overwriting older files where prompted; keep .github and app folders.
3. Commit as: Update approved iwan Android V9
4. Push changes to main (or click Commit changes on GitHub).
5. Open GitHub Actions and choose: Paye Menbare Mola — Android Preview APK (workflow build-v8-preview.yml).
6. Download the NEW successful artifact PayeMenbareMola-V9-PREVIEW-APK.zip, extract and install app-debug.apk.

APK is not bundled here: the Android build must succeed on GitHub.  The preview app id has .preview suffix and can be installed next to the live app.

Video-clips section is an empty moving gallery until real clip URLs are provided.
The Eitaa Back gesture depends partly on the Eitaa app implementation and needs a real-device test.
