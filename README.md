# نسخه آزمایشی «صفحه جدید» V9 — شاخه اصلی سورس

با اجازه صریح مالک، سورس فعال مخزن با نسخه آزمایشی V9 جایگزین شده است. راهنمای ساخت، ویژگی‌های کامل و محدودیت‌های محتوایی در [docs/V9_NEW_IWAN_FA.md](docs/V9_NEW_IWAN_FA.md) است. نسخه رسمی تاریخی **10.4.9** و تگ `v10.4.9` تغییر نکرده‌اند؛ انتشار رسمی جدید انجام نشده است.

ساخت آزمایشی: `gradle --no-daemon :app:assembleDebug`. شناسه نصب مستقل: `ir.nahj.towhidkarbordi.newiwanv9`. آزمون: `python3 scripts/verify_v9_preview.py`.

# پای منبر مولا — پروژه اندروید

برنامه فارسی آموزشی/معارفی اندروید با رابط **Java + Android WebView**.

> **وضعیت هماهنگ‌سازی (۵ نوامبر ۲۰۲۶):** آخرین نسخه ساخته‌شده در گفت‌وگوی توسعه **V10.4** است، اما **سورس کامل V10.4 هنوز به شاخه `main` این مخزن منتقل نشده است**. فایل‌های باینری جدید، به‌ویژه PNG مرجع و ۱۸ پوستر مهمان مولا، در شاخه فعلی وجود ندارند. فایل‌های فعلی پروژه را نسخه نهایی V10.4 فرض نکنید.

فایل تصویری تأییدشده توسط صاحب پروژه **`IMAGE_01_APPROVED_ORIGINAL.png`** است. مشخصات: ۹۴۱×۱۶۷۲ پیکسل، ۲٬۵۷۳٬۲۱۸ بایت، SHA-256:

```
6ebba68081773d58a63dd5f4ec25561f9fb8b86bea46ea62ca7e5e8866c973a1
```

در تمام صفحات همان تصویر باید لایه ثابت معماری ایوان باشد و محتوای تعاملی در لایه مجزا حرکت کند. تصویر اصلی را برش ندهید، بازفشرده نکنید و با خروجی تولید تصویر دیگری جایگزین نکنید.

## ساخت آزمایشی

پروژه دارای گردش‌کار GitHub Actions برای ساخت Debug APK است، اما **تا قبل از انتقال و بررسی تمام فایل‌های سورس و تصویر V10.4، اجرای workflow روی `main` خروجی نسخه جدید V10.4 نیست**.

فایل مرجع، بسته انتقال، سورس یکپارچه و APK آزمایشی V10.4 در گفت‌وگوی توسعه نگهداری شده‌اند و باید ابتدا به شکل کامل و با حفظ هش‌ها منتقل شوند.
