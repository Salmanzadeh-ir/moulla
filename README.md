# پای منبر مولا — سورس آزمایشی V16 (۱۴ نوامبر ۲۰۲۶)

**سورس فعال:** آخرین مجموعه درخواست‌شده صاحب پروژه. **آخرین انتشار رسمی تأییدشده:** V10.4.9؛ فایل، تگ، هش و انتشار تاریخی آن دست‌نخورده‌اند. این مخزن پس از ادغام، صرفاً سورس و APK آزمایشی تولید می‌کند؛ انتشار یا امضای رسمی جدید مجاز نیست.

## ویژگی‌های نسخه فعال

- خانه هفت‌گزینه‌ای با همان ایوان طلایی و سرمه‌ای و ناوبری سابق.
- «یک جمله مهمان مولا»: ۴۸۰ حکمت + ۹ غرائب حدیث، کاملاً آفلاین؛ قرعه تصادفی بدون تکرار تا پایان چرخه، پیام نیت، حرکت تدریجی، متن عربی با فونت **امیری** و **تنها ترجمه فارسی** با ساحل نیمه‌ضخیم.
- دو آیکون مجزای پایین ترجمه: «کپی متن» (شماره، متن عربی، ترجمه و دعوت دقیق به گروه ایتا) و «درشت‌کردن متن» در چهار اندازه؛ تنظیم اندازه ذخیره می‌شود و فقط عربی/فارسی حکمت را تغییر می‌دهد.
- «عکس‌نوشته»: ۹۳ تصویر متفاوت با حجم بهینه و بدون اینترنت، چینش سه‌بعدی با نمایش شانسیِ مرکز و همسایه‌ها، بزرگ‌نمایی در ایوان و **بدون آیکون ارسال**.
- بخش‌های شرح صوتی، توحید، دیدن خدا، شرح اصول کافی، کلیپ‌ها، درباره ما و برگشت با طرح سابق.

## آزمون و ساخت آزمایشی

```sh
python3 scripts/verify_v16_preview.py
python3 scripts/verify_current_preview_lock.py
gradle --no-daemon :app:assembleDebug
```

**شناسه نصب مستقل آزمایشی:** `ir.nahj.towhidkarbordi.newiwanv16`. بررسی روی گوشی برای کلیپ‌ها/لینک‌های خارجی لازم است. APK آزمایشی تنها خروجی خودکار ساخت Debug است و **انتشار رسمی نیست**.

## قفل و تأیید مالک

فایل `design/v16-current-preview-lock.json` هر فایل سورس و دارایی فعال داخل `app/` را با Git SHA-1 قفل می‌کند. Workflow بررسی حتی تغییر یک بایت یا حذف/افزودن فایل را رد می‌کند، مگر اینکه قفل به‌صورت آگاهانه در تغییر مجاز آینده نو شود. `.github/CODEOWNERS` مالک را تعیین می‌کند؛ برای **جلوگیری واقعی از ادغام بدون تأیید مالک** باید در GitHub Settings → Branch protection یا Rulesets، الزام PR و Code owner review و وضعیت `verify-ui-lock` فعال باشد (این اتصال ابزار مدیریت آن تنظیمات را ندارد).
